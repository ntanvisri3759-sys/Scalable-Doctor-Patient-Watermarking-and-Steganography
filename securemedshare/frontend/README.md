# SecureMedShare - Frontend (Phase 1)

React + Vite + Tailwind CSS v4 UI for "Secure and Scalable Medical Data Sharing Using Watermarking and Steganography".

## Run
```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # production build check
```
Requires Node.js 18+ (20 or 22 recommended).

## Demo use
On /login any valid email and an 8+ character password works. Pick a role (Doctor / Patient / Administrator) to preview each interface.

## Status
Phase 1 only: UI, navigation, validation, loading states, toasts, synthetic data.
No real watermarking, steganography, encryption, hashing-against-reference, authentication or storage exists yet.
